# Park Pals Road Trip

Park Pals is a static, browser-based Junior Ranger game. The site files and images are in `outputs/`.

The GitHub Pages workflow in `.github/workflows/deploy-pages.yml` publishes the contents of `outputs/` whenever a change is pushed to `main`. It can also be started manually from the repository's Actions page.

The game stores ranger profiles, progress, favorites, and photo journal entries in the student's browser on that device.
